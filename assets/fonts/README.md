# Built-in fonts

`zig build` installs these to `<prefix>/share/rex/fonts`, where Rex looks
for faces the config leaves out (`src/config/builtin_font.zig`).
`zig build check-fonts` requires each font's copyright (name-table ID 0)
to be the first line of its OFL file.

Google Sans Code v6.001, the variable upright and italic faces
(`variable/`) and `OFL.txt` of the
[v6.001 release](https://github.com/googlefonts/googlesans-code/releases/download/v6.001/GoogleSansCode-v6.001.zip),
copied unchanged, under the SIL Open Font License 1.1. SHA-256:

```
c9649573afcd966f61096b1e9c3c3115e7b54315ca2adf9839c6f8b17d5f8e1f  GoogleSansCode[wght].ttf
bdf116292f27aca16e2aefb5534042a25f244d3a9187a521ce97fc2117a4a844  GoogleSansCode-Italic[wght].ttf
ff8f4fbc4f1a71c7d4c6481c48dc2b21c43f8dc15872536667fee45c15d20928  OFL-GoogleSansCode.txt
```

To update, replace the files from a new release, update this table and
the version, and run `zig build check-fonts`.

## Inter (the UI font)

Inter 4.1, the static upright faces `Inter-Regular.ttf`,
`Inter-Medium.ttf` and `Inter-SemiBold.ttf` (`extras/ttf/`) and
`LICENSE.txt` of the
[v4.1 release](https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip),
copied unchanged (the license as `OFL-Inter.txt`), under the SIL Open Font
License 1.1. The UI kit sets its text in them (ADR 0009). SHA-256:

```
40d692fce188e4471e2b3cba937be967878f631ad3ebbbdcd587687c7ebe0c82  Inter-Regular.ttf
97ad806f526e41546d46365bb3a393145f75b7b1568913db74549ad8b8dba872  Inter-Medium.ttf
78a843fade9d4612a5567302fb595b56976eb5fcebf4fea5a5912d638bafcde3  Inter-SemiBold.ttf
262481e844521b326f5ecd053e59b98c8b2da78c8ee1bdbb6e8174305e54935a  OFL-Inter.txt
```

The static faces, not `InterVariable.ttf`: FreeType's GPOS kerning reads
only plain x-advance pairs, and the variable face stores its class pairs
with variation data, so it gets no kerning (measured 2026-11-12: A V is
0 px there and about -1 px at 14 px in the static faces).

The license file starts "Copyright (c) 2016 ..." with the project URL,
while the fonts' name tables say "Copyright 2016 The Inter Project
Authors"; `check-fonts` compares the two without the "(c)" and the URL.

## Lucide (the UI kit's icons)

Lucide 1.62.0, `lucide.ttf` of
[lucide-font-1.62.0.zip](https://github.com/lucide-icons/lucide/releases/download/1.62.0/lucide-font-1.62.0.zip),
copied unchanged, and `LICENSE` of the repository at that tag (as
`LICENSE-Lucide.txt`), under the ISC License; the icons taken over from
Feather are MIT, as that file says. `lucide.ttf` is subset at build time (`tools/fonts/subset.zig`) down to
the glyphs in `tools/gen/icons.txt` and embedded directly into the binary;
only `LICENSE-Lucide.txt` is installed alongside the other built-in faces.
`src/kit/icons.zig` is generated by `zig build gen-icons`. SHA-256:

```
695a71b7a9f185d2c6d606640db2687c2c93044abba09ded7fcec28b168a70f4  lucide.ttf
b495047bd93a9b06913511076f504daba17d5bbeb3e0650f3bb53a4220329c57  LICENSE-Lucide.txt
```

`zig build check-fonts` does not cover it: the font's name table carries
no copyright line to compare. To update, replace both files, update this
table and the version, and run `zig build gen-icons`.
